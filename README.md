# 사진 문장 넣기

사진 위에 여러 문장을 직접 배치하고, 완성된 이미지를 사진 보관함에 저장할 수 있는 간단한 웹앱입니다.

별도의 앱 설치나 회원가입 없이 iPhone Safari에서 열어 **홈 화면에 추가**하면 일반 앱처럼 사용할 수 있습니다. 한 번 열어 필요한 파일을 받아 두면 인터넷 연결이 없는 상황에서도 작업할 수 있습니다.

## 이런 분께 제안합니다

- 사진 전후 비교에 짧은 설명을 넣고 싶은 분
- 현장 사진에 작업 단계나 메모를 표시하고 싶은 분
- 복잡한 편집 앱 대신 빠르게 문장을 얹고 싶은 분
- 사진을 외부 서버에 올리지 않고 휴대폰 안에서 처리하고 싶은 분

## 주요 기능

- 사진 보관함에서 사진 선택
- 최대 8개의 문장 입력
- 문장별 자동 색상: 흰색, 빨강, 노랑, 녹색, 주황, 파랑, 보라, 검정
- 회색 반투명 문장 상자
- 사진 위에서 손가락으로 문장 상자를 직접 드래그해 위치 조정
- 원본 사진 크기를 유지한 JPG 생성
- EXIF 위치·촬영 정보는 결과 이미지에서 제거
- 완성 이미지를 바로 보기 화면으로 열어 사진 보관함에 저장
- 홈 화면 추가 및 오프라인 사용 지원

## 사용 방법

1. 앱을 열고 **사진 선택**을 누릅니다.
2. 필요한 문장을 입력합니다. 비워 둔 칸은 사진에 표시되지 않습니다.
3. 사진 위의 문장 상자를 손가락으로 끌어 원하는 위치에 놓습니다.
4. **사진으로 저장 / 공유**를 누릅니다.
5. 열린 완성 이미지 화면에서 iPhone의 공유 버튼을 누르고 **이미지 저장**을 선택합니다.

## 개인정보

선택한 사진과 입력한 문장은 외부 서버로 전송되지 않습니다. 모든 편집은 사용자의 브라우저 안에서 이루어집니다.

## 오프라인 사용

처음에는 인터넷에 연결된 상태에서 앱을 열고 홈 화면에 추가해 주세요. 이후에는 PC 서버 없이도 사용할 수 있습니다. 다만 iPhone의 웹사이트 데이터가 삭제되거나 저장 공간 정리로 캐시가 지워진 경우에는 다시 인터넷에 연결해 앱을 한 번 열어야 합니다.

## 직접 설치하기

이 저장소의 파일을 웹 서버 또는 GitHub Pages에 올린 뒤, iPhone Safari에서 해당 주소를 열어 **공유 → 홈 화면에 추가**를 선택하면 됩니다.

## 제안 및 개선 아이디어

이 앱은 복잡한 이미지 편집보다 "사진에 짧은 문장을 빠르게 남기는 일"에 집중합니다. 사용 중 불편한 점이나 필요한 기능이 있다면 Issue에 남겨 주세요.
