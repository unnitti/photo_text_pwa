# 사진에 글 넣기

사진 위에 여러 줄의 글을 배치하고, 완성된 이미지를 저장할 수 있는 간단한 웹앱입니다.

특정 업무에서 사진에 설명이나 기록을 빠르게 표시하기 위한 용도로 만들었습니다.

## 사용 환경

- **iPhone + Safari 기준으로 개발 및 테스트**
- 별도의 앱 설치나 회원가입이 필요하지 않습니다.
- Safari에서 홈 화면에 추가하여 일반 앱처럼 사용할 수 있습니다.
- Android에서도 동작할 가능성이 있지만 별도 테스트는 하지 않았습니다.

## 기본 사용법

### 1. 글 입력

화면의 입력란에 사진에 넣을 글을 입력합니다.

- 기본 2줄로 시작합니다.
- `+ 글 추가`로 최대 8줄까지 사용할 수 있습니다.
- 비어 있는 줄은 사진에 표시되지 않습니다.
- 마지막 줄에 글을 입력하면 다음 줄이 자동으로 추가됩니다.

### 2. 글자 크기와 색상 변경

각 줄의 버튼을 눌러 글자 크기와 색상을 변경할 수 있습니다.

글자 크기는 다음 세 단계입니다.

**대 → 소 → 중 → 대**

색상은 정해진 순서대로 순환합니다.

### 3. 사진 선택

사진 보관함에서 사진을 선택하거나 새로 촬영합니다.

사진은 원본 해상도로 불러옵니다.

### 4. 글 위치 조정

사진 위에 표시된 글 상자를 손가락으로 끌어 원하는 위치에 배치합니다.

사진 자체는 두 손가락으로 확대하거나 이동할 수 있습니다.

확대된 상태에서 글 위치를 조정하면 작은 글씨를 배치하기 편합니다.

사진을 원래 크기에 맞추려면 확대/이동을 초기화할 수 있습니다.

### 5. 저장

`저장`을 누르면 완성된 JPEG 이미지가 열립니다.

iPhone에서는 열린 이미지 화면에서

**공유 → 이미지 저장**

을 선택하여 사진 보관함에 저장합니다.

## 편리한 기능

### 6자리 숫자 자동 날짜 변환

입력란에서 포커스를 벗어나면 연속된 6자리 숫자를 날짜 형식으로 자동 변환합니다.

예:

```text
260923
```

→

```text
26.09.23
```

6자리보다 짧거나 긴 숫자 덩어리는 변환하지 않습니다.

예를 들어 문장 안에 여러 개의 6자리 숫자가 있다면 각각 별도로 변환될 수 있습니다.

### 줄 삭제

각 줄의 `×` 버튼을 누르면 해당 줄의 글과 글자 설정이 초기 상태로 돌아갑니다.

### 글 모두 지우기

사진은 그대로 두고 입력한 글만 모두 지울 수 있습니다.

잠시 동안 `되돌리기`를 사용할 수 있습니다.

※ 되돌리기는 글 삭제에 대한 기능이며 사진 자체를 되돌리지는 않습니다.

### 사진 바꾸기

사진을 다른 사진으로 바꿀 수 있습니다.

기존에 배치한 글의 위치는 유지됩니다.

## 사진 및 개인정보

사진과 입력한 글은 외부 서버로 전송되지 않습니다.

사진 편집은 사용자의 브라우저 안에서 이루어집니다.

완성된 이미지는 원본 사진을 캔버스에 다시 그려 JPEG로 저장합니다.

## 오프라인 사용

처음 사용할 때는 인터넷에 연결된 상태에서 앱을 열어 주세요.

Safari의 **공유 → 홈 화면에 추가**를 이용하면 홈 화면에서 앱처럼 실행할 수 있습니다.

앱의 주요 파일은 브라우저에 캐시되므로 이후에는 인터넷이 없는 상황에서도 기본적인 사용이 가능합니다.

다만 iPhone에서 웹사이트 데이터나 캐시가 삭제되었거나 저장 공간 등의 이유로 캐시가 사라진 경우에는 인터넷에 연결하여 앱을 다시 열어야 할 수 있습니다.

## 알아두세요

이 앱은 특정 업무 환경에서 사용하기 위해 만든 간단한 도구입니다.

일반적인 사진 편집 프로그램을 목적으로 하지 않습니다.

특히 다음과 같은 상황에서는 원하는 결과와 다를 수 있습니다.

- 매우 큰 사진을 처리하는 경우
- 브라우저 또는 iOS 환경이 다른 경우
- 예상하지 못한 입력이나 조작을 하는 경우

중요한 사진은 저장 후 결과를 한 번 확인해 주세요.

## 문제가 생겼을 때

### 사진이 저장되지 않는 경우

저장 버튼을 누른 뒤 완성 이미지가 열렸는지 확인하세요.

iPhone에서는 완성된 이미지 화면에서 **공유 → 이미지 저장**을 선택해야 사진 보관함에 저장됩니다.

### 클립보드나 사진 접근 등이 이상한 경우

Safari에서 앱을 다시 열어 보세요.

필요하다면 홈 화면에 추가한 앱을 종료한 뒤 다시 실행해 보세요.

### 앱이 예전 버전처럼 보이는 경우

인터넷에 연결된 상태에서 앱을 다시 열어 보세요.

새 버전이 내려받아졌더라도 실제 적용은 다음 실행 시 이루어질 수 있습니다.

### 그 밖의 문제가 발생한 경우

가능하면 다음 내용을 함께 알려 주세요.

- 사용한 iPhone 모델
- iOS 버전
- Safari에서 사용했는지 홈 화면에서 사용했는지
- 어떤 사진과 입력을 사용했는지
- 어떤 단계에서 문제가 발생했는지
